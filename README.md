# TV·OTT 믹스 플래너

총 광고 예산과 TV·OTT 비중을 넣으면 비중별 예상 통합 도달률(Reach 1+ / 3+)을 곡선과 표로 보여 주는 플래닝 사이트입니다.

- TV 도달: Nielsen 시뮬레이션 769건 Hill 곡선 적합(보수 / 기준 / 낙관)
- OTT 도달: 1~30억 곡선 선형보간(넷플릭스 80%+티빙 20% / 넷플릭스 100%), 30억 이후 마지막 값 유지
- 통합 도달 = TV + OTT − min(중복계수 × TV × OTT, min(TV, OTT)), 중복계수 기본 1.08(한국리서치 F30-45 최근 1주)
- 최적화: OTT 비중 0~100%를 0.5%p 간격으로 전수 탐색, 최대 대비 허용 오차(기본 0.2%p) 이내를 허용 구간으로 표시

단일 `index.html` 파일로 동작합니다(빌드 없음).
